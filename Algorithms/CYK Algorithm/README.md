# Cocke-Younger-Kasami (CYK) Algorithm in C#

### 1. Introduction
The Cocke-Younger-Kasami (CYK or CKY) algorithm is a standard dynamic programming algorithm for determining whether a given string of tokens can be generated by a Context-Free Grammar (CFG) and, optionally, constructing its concrete parse tree. 

To apply CYK, the input context-free grammar must be in **Chomsky Normal Form (CNF)**, where all production rules are strictly of the form:
- $A \to BC$ (a non-terminal derives exactly two non-terminals)
- $A \to a$ (a non-terminal derives a single terminal symbol)

CYK is commonly used in computational linguistics, natural language processing, formal language theory, and compiler front-ends.

---

### 2. Usage

```csharp
using System;
using CykAlgorithm;

class Example
{
    public static void Run()
    {
        // Define grammar with Start symbol 'S'
        var grammar = new Grammar("S");

        // S -> NP VP
        grammar.AddRule(CnfRule.CreateBinary("S", "NP", "VP"));
        // VP -> V NP
        grammar.AddRule(CnfRule.CreateBinary("VP", "V", "NP"));
        // NP -> "she" | "an" "apple" (or simply terminals)
        grammar.AddRule(CnfRule.CreateTerminal("NP", "she"));
        grammar.AddRule(CnfRule.CreateTerminal("NP", "apples"));
        // V -> "eats"
        grammar.AddRule(CnfRule.CreateTerminal("V", "eats"));

        var parser = new CykParser(grammar);

        string[] sentence = new string[] { "she", "eats", "apples" };
        bool isValid = parser.Parse(sentence);
        Console.WriteLine($"Sentence valid: {isValid}"); // Output: True

        ParseTreeNode? tree = parser.ParseTree(sentence);
        if (tree != null)
        {
            Console.WriteLine($"Root symbol: {tree.Symbol}"); // Output: S
            Console.WriteLine($"Left child: {tree.LeftChild?.Symbol} ({tree.LeftChild?.TerminalValue})"); // NP (she)
            Console.WriteLine($"Right child: {tree.RightChild?.Symbol}"); // VP
        }
    }
}
```

---

### 3. Detailed Explanation

1. **Data Structures**:
   - `CnfRule`: Encapsulates both binary and terminal production rules.
   - `Grammar`: Organizes rules and maps terminals/pairs back to their left-hand non-terminals using hash tables for $O(1)$ rule lookups during table population.
   - `ParseTreeNode`: Represents a concrete node in the binary syntax tree.
   - `CykParser`: Implements membership verification and tree extraction via backtrack pointers.

2. **Dynamic Programming Table**:
   - Let $n$ be the length of the input token sequence.
   - We define a 2D array of sets `table[length - 1, start]` representing non-terminals capable of generating the substring of length `length` starting at index `start`.
   - **Base Case (Length = 1)**: For each token at index $i$, find all non-terminals $A$ such that $A \to \text{token}[i]$ is a rule.
   - **Inductive Step (Length = $2 \dots n$)**: For each start index and split point $k$ ($1 \le k < \text{length}$), examine derivations $A \to B\,C$ where $B \in \text{table}[k-1, \text{start}]$ and $C \in \text{table}[\text{length}-k-1, \text{start}+k]$.
   - **Acceptance**: The string belongs to the grammar if the start symbol $S \in \text{table}[n-1, 0]$.

3. **Parse Tree Reconstruction**:
   - During table construction, `ParseTree` records backtrack pointers `(split, leftSymbol, rightSymbol)` for each reachable non-terminal in a cell.
   - A recursive helper function traces back from `table[n-1, 0][StartSymbol]` to reconstruct the full syntax tree in $O(n)$ time.

---

### 4. Complexity Analysis

- **Time Complexity**:
  - **Parsing / Verification**: $O(n^3 \cdot |R|)$, where $n$ is the input length and $|R|$ is the number of grammar production rules. The three nested loops iterate over substring length, starting index, and split partitions.
  - **Tree Construction (Backtracking)**: $O(n)$ recursive node expansions once the table is populated.
- **Space Complexity**:
  - **Table Storage**: $O(n^2 \cdot |V|)$, where $n$ is the token count and $|V|$ is the total number of non-terminal symbols in the grammar.
