# Gnome Sort\n\n## Introduction\nGnome Sort is a simple comparison sorting algorithm that is similar to Insertion Sort. It works by inspecting adjacent elements, swapping them if they are in the wrong order, and then moving back one position to re-evaluate the new ordering. This algorithm is easy to understand and implement, making it suitable for educational purposes and small datasets.\n\n## Usage\nHere is an example of how to use the Gnome Sort algorithm in C#:  \n```csharp\nint[] numbers = { 5, 3, 2, 4, 1 };\nGnomeSorter.Sort(numbers);\n// numbers is now sorted: { 1, 2, 3, 4, 5 }\n```\n\n## Detailed Explanation\nThe Gnome Sort algorithm works by maintaining an index that traverses the array. If the current element is greater than or equal to the previous element, it moves forward. If it is less, it swaps the two elements and moves back one position to check the new ordering. This process continues until the entire array is sorted. The algorithm is in-place, meaning it does not require additional storage for sorting.\n\n## Complexity Analysis\n- **Time Complexity:**  \n  - Worst-case: O(n^2)  \n  - Average-case: O(n^2)  \n  - Best-case: O(n) (when the array is already sorted)  \n- **Space Complexity:** O(1) (in-place sorting)
